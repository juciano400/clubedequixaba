# Exportação completa para GitHub

Este repositório contém a versão exportada do Clube de Leitura de Quixaba, com o código React, estilos, configuração, documentação e os assets visuais usados durante o desenvolvimento.

As imagens estão em `client/public/assets/` e as referências da cópia do GitHub usam caminhos locais `/assets/...`, para que o projeto continue funcionando quando clonado fora do ambiente Manus.

## Executar localmente

```bash
pnpm install
pnpm dev
```

A pasta `client/public/assets/` também preserva os demais assets visuais gerados ou enviados durante o projeto para manter o material completo.
